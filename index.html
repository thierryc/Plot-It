From a line
to a drawing.

Prepare artwork, set type, and send your drawing to an EBB pen plotter. A small workspace for the things you want to put on paper.

Open Plot-it ↗Self-hosting documentation

Editing and simulation need no installation. Direct USB plotting requires desktop Chrome or Edge with Web Serial, HTTPS, and your permission to connect.

One workspace. Your drawing.

01

Make the marks

Import an SVG, draw freehand, add shapes, or set type. Keep your artwork editable and save it as a Plot-it document.

02

See the route

Preview planned paths in simulation. Arrange pen passes and review the drawing before connecting hardware.

03

Put it on paper

Connect an EBB over USB from your browser, or install the separate Node server on your own computer or Pi.

Type made for paths

Meet OpenPlotFont.

Plot-it reads OpenPlotFont 0.2 and 0.3 to preserve original centerline strokes, curves, and drawing order. Fonts may also contain filled regions and embedded text-layout rules.

OpenPlotFont is a separate project. Each bundled font retains its own attribution and license.

A work in progress

Help shape
what comes next.

This alpha is in active development. The project is not viable yet and is not ready for production use. Hardware coverage is limited: an EBB controller alone does not establish compatibility with every plotter.

I do not own an AxiDraw or NextDraw, so I have not tested Plot-it on either. Help testing and improving compatibility is welcome.
