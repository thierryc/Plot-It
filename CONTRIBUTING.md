# Contributing

You can help without a plotter: test editing and simulation, report a bug, suggest a feature or improve documentation. Start with the [alpha test guide](docs/ALPHA_TESTING.md) for limitations, issue reporting and logs.

For code changes, follow [Development](docs/DEVELOPMENT.md). Keep changes focused, describe the resulting behavior and include relevant verification. Discuss a large feature in an issue first. Software tests use simulated transports; do not connect hardware just to test a pull request. Physical results must identify the actual build and setup.

Contribute only material you have the right to license. Original application/core contributions use Apache-2.0; OpenPlotFont uses MIT; assets retain their stated terms. Identify any copied or adapted material with its exact source, revision and complete notices. See [distribution notes](docs/LICENSING.md).
