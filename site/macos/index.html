Connect the agent you use.

Install PlotIt MCP in Applications and keep it open. In its menu bar, choose Set Up… → Configure agent apps. Choose your client below; you can prepare and simulate drawings before connecting a plotter.

Codex

  1. Choose Install… in the Codex row.
  2. Review the command and configuration destination, then confirm.
  3. Start a new local Codex chat and try the first prompt below.

Use Locate App… if Codex isn't found. The setup uses your Codex configuration, including a custom configuration folder.

Try your first prompt.

Use PlotIt to check my setup, list the stroke fonts, and prepare a small hello-world drawing. Show me the preview and simulate it before starting. When I ask you to plot, show the live progress card.

Ask the agent to show PlotIt's setup card if you want help with configuration. Secure the paper and physically position the carriage before confirming the origin. A connection or a completed simulation never starts a physical drawing.

Your agent. Your plotter. This Mac.

PlotIt MCP is a native macOS 14+ menu-bar app with its own bundled runtime. It does not require a separate Node installation or a PlotIt account. The universal download runs on Apple Silicon and Intel Macs, is Developer ID signed, and is notarized by Apple. Open the DMG, drag PlotIt MCP to Applications, then open the app to set up your plotter.

Choose your machine, paper preset or custom size, pen heights and USB device in the native app or an interactive setup card. The agent can help configure and connect your plotter when requested.

See what is happening.

A live conversation card shows the full drawing preview, estimated progress, elapsed and remaining time, and Pause, Resume and Stop controls. Pen changes show clear instructions. Clients that do not support interactive MCP Apps retain useful tools, text and PNG previews.

Agent control becomes available when the connected plotter has an established origin and the Mac companion is present. Turn it Off at any time to block new starts and agent resumes. Becoming ready never starts a drawing.

Keep the editor you already use.

The browser editor remains available without installing the Mac app. Use it to edit and simulate drawings, then exchange SVG files with the companion workflow. These are separate workspaces; installing or removing the Mac app does not alter the web app.

An experimental first release.

Hardware profiles require testing on the actual machine. Simulation does not establish AxiDraw, NextDraw or other plotter compatibility. Start with a small preview and pen calibration. Carriage positioning, securing paper and loading pens remain physical tasks.

Storage is local. Your chosen agent receives the tool results and previews you request under that agent's own privacy policy. The current integration uses local clients; a remote ChatGPT web bridge is not included.
