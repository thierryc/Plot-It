# Mac website imagery

The public images live in `public/macos/media/`. HTML uses `%BASE_URL%macos/media/` for both image sources and full-size links, so they share stable URLs in the production build.

- `app-icon.png`: the designer-supplied 512-pixel magenta Plot-It icon, shared with `macos/Sources/PlotItApp/Resources/PlotItAppIcon.png` and `public/icon.png`. The source glyph's subtraction masks are already resolved in the native icon assets; do not replace this with a raw Glyphs SVG export.
- `mac-setup.png` and `agent-connections.png`: native SwiftUI views rendered by `UISnapshotTests`, using the app's preview model and example configuration. The capture does not start a service, connect USB, or change an agent's configuration.
- `connection-menu.png` and `connection-menu-disconnected.png`: current connection-menu content with example completed-job and connected/disconnected states, including the connection-aware pen symbols and compact More button. The native MenuBarExtra window supplies the real app’s material and corner clipping; these content captures are framed by the website.
- `app-settings.png`: App settings with Automatic updates on. Preview controls display normally but no updater is started and no update preferences are written.
- `plot-progress.png`: the bundled MCP Apps progress card captured inside `scripts/preview-plot-progress.mjs`, using simulated drawing data. This is a component preview, not an assertion that a particular agent client renders cards or that a physical plot has completed.

Native captures can be regenerated with `PLOTIT_CAPTURE_DIR=/tmp/plotit-site-media swift test --package-path macos --filter UISnapshotTests`. For foreground glass/control rendering, also set `PLOTIT_ACTIVE_CAPTURES=1` and `PLOTIT_SCREENSHOT_HELPER` to the screenshot skill’s `scripts/take_screenshot.py` after its screen-recording permission preflight. This captures only the isolated preview windows; regular tests remain offscreen. The active-control override is applied only to this Window Server capture path, since forcing it in `cacheDisplay` omits GPU-rendered controls. Copy `setup-0.png` to `mac-setup.png`, `setup-1.png` to `agent-connections.png`, `app-settings.png` to the same name, `menu-connected.png` to `connection-menu.png` and `menu-disconnected.png` to `connection-menu-disconnected.png`. Set `PLOTIT_PREVIEW_PATH` to a publishable drawing preview to include it in the menu captures. Use the current release build as the query version for replaced assets to refresh cached website images. The website captions disclose example/simulated data. Retain readable controls, alt text, and the original aspect ratios.

For card screenshots, capture the iframe using document coordinates (its viewport rectangle plus page scroll offsets), after the progress-bar transition settles. Exclude the preview host controls. Screenshot bytes may be JPEG; explicitly convert to PNG before saving a `.png` asset and inspect the resulting image.
