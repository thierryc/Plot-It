Use the browser app

  1. Open Plot-it, then import SVG artwork, draw, or add text.
  2. Choose Simulation to review the planned drawing without hardware.
  3. For hardware, connect your EBB to this computer and choose Direct USB. Close Saxi, other apps, and browser tabs that already own its connection.
  4. Click Connect and select the USB device when your browser asks. Connection does not start a drawing.
  5. Establish the physical origin and verify pen heights and orientation before starting. Document paper size does not enforce machine travel limits.

Editing and simulation need no installation. USB plotting needs a supported desktop browser, HTTPS, and permission to use the device. Desktop Chrome and Edge expose Web Serial; the app checks actual availability. Mobile USB plotting is not advertised.

Save a .plit.json document to keep artwork and settings; export SVG for other tools. Browser storage belongs to the hostname you use, so export documents before changing domains.

Hardware compatibility

Controller documentation is evidence about the EBB protocol, not validation of a complete machine. Board revisions, servo configuration, firmware, orientation, scaling, and travel limits matter.

Current Plot-it hardware status
HardwareStatusWhat is established
Author’s EBB setupLimited physical testingUSB communication and paper drawing have been exercised on the author’s setup. This does not validate other machines or every feature.
AxiDrawuntestedUses an EBB controller. No AxiDraw hardware tests by the author; the profile name in the app is not a support certification.
Bantam Tools NextDrawcompatibility not establishedUses an EBB controller, but its narrow-band brushless pen lift differs from Plot-it’s current servo configuration. Pen lift and homing need dedicated validation before Plot-it can claim support.

I do not own an AxiDraw or NextDraw, so I have not tested Plot-it on either. Help testing and improving compatibility is welcome.

Both vendor links meet the EBB-controller condition. This is not a claim that their boards have an identical hardware revision. Other machines are not listed merely because they also use EBB electronics.

OpenPlotFont and licensing

OpenPlotFont is a separate draft font-format project. Plot-it supports drafts 0.2 and 0.3 under the OpenPlotFont identifier, loaded from .opf or .opf.json files. Stroke fonts preserve original drawing operations; ordinary OpenType fonts produce outlines.

Plot-it is licensed AGPL-3.0-only. Imported fonts have their own terms and notices; they are not all relicensed under the application’s license. Attribution links are available in the app.

Contribute to the beta

  • Report a bug or ask for help with reproduction steps and your browser/OS.
  • Share a hardware report with model, board/firmware, configuration, and observed results. NextDraw remains unvalidated; testing must account for its different servo.
  • Improve documentation or propose code changes through a pull request.
  • Star the repository and share the project.

Software tests and physical hardware acceptance are recorded separately. Tests on one controller do not certify other plotters.
