Import, simulate, save

  1. Download the small test drawing, then open Plot-it and choose Import SVG. You can also start with Add text.
  2. Set the selected object's Width and Height to 80 mm in the inspector. Imports start at a default display size; this restores the intended 50 mm square and 20 mm circle. Keep it inside the paper's safe margin.
  3. Choose Plot at the top right, wait for preparation, then click Simulate in the sidebar footer. No hardware destination is needed.
  4. Try Pause, Resume, and Stop. Choose Edit to return to your artwork.
  5. Use the top-left menu to Save an editable .plit.json document or export SVG for other tools.

Artwork and loaded fonts stay in your browser. Save document backups before clearing browser data or changing hostname. SVG export does not preserve every editable text or fill setting.

Before USB plotting

Direct USB needs desktop Chrome or Edge with Web Serial, HTTPS, and permission to select your device. Close other apps or tabs using the same board. Mobile USB plotting is not advertised.

  1. Check your machine's status below and match its actual model, servo, orientation, and scaling.
  2. In Plot, select Direct USB · this computer and click Connect. Connection does not start a drawing.
  3. Calibrate Up/Down heights, place the carriage at the physical origin, and use Set origin. Paper size does not identify the machine's travel area.
  4. Use raised Preview bounds. It returns and releases motors; restore the physical reference and set origin again before plotting.
  5. Load the indicated pen and choose Start with this pen. After a fault or interrupted motion, recover origin and prepare a fresh job.

I do not own an AxiDraw or NextDraw, so I have not tested Plot-it on either. Help testing your exact configuration is welcome.

SM compatibility starts at firmware 2.8.1; NextDraw requires 3.0.2 or newer. Explicit S-curve targets 3.1.7; physical Auto stays on SM pending acceptance. Plot-it does not update firmware.

Fonts and source

OpenPlotFont is a separate font-format project. Plot-it reads drafts 0.2/0.3 and ordinary TTF/OTF fonts. Stroke fonts retain their drawing operations; outline fonts produce contours. Each font retains its source license.

Use Text → Load a font to import separately obtained fonts locally. The two GPL ISO3098 faces are excluded from the default bundle. See optional font packs and licenses.
