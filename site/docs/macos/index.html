PlotIt MCP · Mac guide

From your agent
to paper.

A local macOS companion for agent-assisted USB plotting. macOS 14 or later; no separate Node installation.

Install the Mac app

Download the signed and notarized Universal alpha from the Mac companion page. The same download runs on Apple Silicon and Intel Macs with macOS 14 or later. Open the DMG and drag PlotIt MCP.app into Applications before configuring agents.

Open the app and find its menu-bar icon. Development packages are ad-hoc signed and are distinct from the signed, notarized public release. Verify a public download against its SHA-256 checksum. Keep normal macOS security protections enabled.

Set up the plotter

  1. Open Set Up. Choose the machine, USB device, paper format and pen heights. Custom dimensions are in millimetres. Save & Continue preserves changes.
  2. Connect the plotter. Test pen up/down using the saved heights. Position the carriage at the intended drawing origin and secure the paper, then capture the current position as origin.
  3. Configure your agent app through the reviewed installation action. Start a new agent session; restart Claude Desktop if needed. Run the server test and copy the first prompt.

You can also ask the agent to open PlotIt's setup card. It uses the same saved settings and hardware operations. Capturing origin never homes the machine, and the agent must not infer physical placement from an image. Setup controls are unavailable during an active plot.

Use Connect / Disconnect to control the connection. The toolbar icon gains a lightning bolt when connected. Saved configuration, an established physical origin and the native app open are required before drawing; there is no separate agent-permission switch.

Connect your agent

Keep PlotIt MCP open on the same Mac as your agent. From the menu bar choose Set Up…, then Configure agent apps. Each Install… action shows the destination and launch command for review. Existing files are backed up, and a conflicting PlotIt entry requires an explicit replacement.

After installing a connection, choose Test connection → Run Server Test. A successful test confirms MCP initialization and tool discovery. To check the agent itself, start a fresh client session and use the first prompt below. No USB connection is needed to prepare artwork or run a simulation.

Connect Codex

  1. In PlotIt's Configure agent apps step, choose Install… beside Codex. Review and confirm the change.
  2. If Codex isn't detected, choose Locate App… and select your local Codex app or executable. For a custom configuration location, expand Other clients & advanced setup → Choose Codex Configuration Folder….
  3. Start a new local Codex chat or CLI session. Keep PlotIt MCP open, then paste the first prompt below.
  4. Check Agent connected in PlotIt. In the Codex CLI, /mcp shows active servers; codex mcp list lists saved connections.
Manual Codex configuration

Use this instead of the app's Install action. Add one PlotIt table to ~/.codex/config.toml, or the config.toml in your chosen CODEX_HOME. Keep your existing configuration and avoid duplicate PlotIt tables.

[mcp_servers.plotit]
command = "/Applications/PlotIt MCP.app/Contents/MacOS/plotit-mcp"
args = []

If the Codex CLI is installed, the equivalent command is:

codex mcp add plotit -- "/Applications/PlotIt MCP.app/Contents/MacOS/plotit-mcp"

Start a new local Codex session after saving. The launch path must match where you installed the app.

Connect Claude Desktop

  1. Install Claude Desktop on this Mac and open it at least once.
  2. In PlotIt's Configure agent apps step, choose Install… beside Claude Desktop. Review the configuration file and confirm.
  3. Fully quit Claude Desktop with ⌘Q, then reopen it. Start a desktop chat and paste the first prompt below.
  4. Check PlotIt's Agent connected status. Claude's local MCP server settings show connection status and logs. In current layouts, look under Settings → Desktop app → Extensions → Manage → Local MCP servers; older layouts use Settings → Developer.

This connects the local desktop chat to PlotIt on your Mac. The remote connector form in claude.ai, and Cowork's remote connectors, cannot launch this local app.

Manual Claude Desktop configuration

Merge the plotit entry into ~/Library/Application Support/Claude/claude_desktop_config.json. Preserve any other entries in mcpServers; the example below shows a file with only PlotIt.

{
  "mcpServers": {
    "plotit": {
      "command": "/Applications/PlotIt MCP.app/Contents/MacOS/plotit-mcp",
      "args": []
    }
  }
}

Save valid JSON, then fully quit and reopen Claude Desktop. PlotIt's Other clients & advanced setup → Copy Configuration supplies the launch definition for your actual installation.

Connect Claude Code

  1. Install Claude Code on this Mac. In PlotIt's Configure agent apps step, choose Install… beside Claude Code.
  2. If needed, use Locate CLI… to find the claude executable. Review and confirm the installation. PlotIt adds a user-scope local stdio server.
  3. Start a new local Claude Code session and run /mcp. Look for plotit, then use the first prompt below.
Manual Claude Code command

Use this instead of the Install action. User scope makes the connection available across your local projects:

claude mcp add --scope user --transport stdio plotit -- "/Applications/PlotIt MCP.app/Contents/MacOS/plotit-mcp"

Run claude mcp get plotit to inspect the saved connection. Use your normal Claude Code installation and configuration environment; PlotIt needs no separate Node installation.

Check the connection with one prompt

Use PlotIt to check my setup, list the stroke fonts, and prepare a small hello-world drawing. Show me the preview and simulate it before starting. When I ask you to plot, show the live progress card.

You can also choose Copy First Prompt in the app's Test connection step. Ask for PlotIt's setup card if you want the agent to help configure the plotter. Interactive setup and progress cards require MCP Apps support in your client version. Without it, use the same tools and PNG previews through text.

If the client cannot find PlotIt, verify the app is in Applications, check that you installed the connection for the correct client, and start a fresh session. A successful server test and a connected agent are separate checks. Review any client error or local server log before reinstalling.

Prepare, preview, plot

Ask: “Use PlotIt to check my setup, prepare a small hello-world drawing, show its preview and simulate it before starting.” Inspect the preview, then request the physical plot. Ask for the live progress card to follow it in one place.

The card shows estimated progress and timing, current state and Pause/Resume/Stop. Stop is a controlled stop: wait for motion to settle. Load the requested pen and use Continue in the native companion at physical pen changes. Progress only reaches 100% after the plotter confirms completion.

The web editor and companion remain separate. Export outlined SVG from the editor when you want to exchange artwork. MCP lettering uses bundled centerline stroke fonts.

If something is interrupted

  • No device: check USB and power, refresh devices, and select the exact port if multiple EBB boards are present.
  • Agent configured but disconnected: start a new agent session or restart the agent app, then run the server test.
  • Card not rendered: use the same setup and job tools through text. Interactive UI support depends on the specific client.
  • Settings changed elsewhere: reload saved settings before making new edits. Your draft is not silently overwritten.
  • USB loss or restart: inspect the drawing and restore the physical origin before preparing a new job. Uncertain work is never replayed automatically.

Closing an agent does not cancel a drawing. Use the companion's Pause/Stop controls. Quitting offers Wait and Quit or Stop and Quit while a drawing is active.

Update or remove

From alpha 2 (build 7), PlotIt checks daily and downloads signed updates from GitHub. Automatic updates are on by default. Open Settings… → App settings and turn Automatic updates off to disable automatic checks and downloads. Your choice is saved. Check for Updates… remains available there and in About & Help. Choose Install & Restart when ready, or Later to keep working; a downloaded update can install on normal quit without reopening. Updates wait for drawing, calibration and unsaved settings. Build 6 and earlier need one manual upgrade: quit while idle, replace the app in Applications and reopen. Keep a backup of the local data folder and previous release. About & Help can open the data folder. Data is stored under ~/Library/Application Support/PlotIt MCP.

To uninstall, remove the PlotIt connection from each configured agent in the app, turn off Open at Login, quit while idle and move the app to Trash. Local drawings, jobs and backups remain until you remove them. The web app is unaffected.

Privacy and support

PlotIt MCP has no account, analytics backend or internet listener. The chosen agent receives requested tool results and previews under its own privacy policy. Review logs before sharing them.

For help, include app version/build, macOS and CPU architecture, agent/client version, plotter model and the observed state in a GitHub issue. Hardware profiles remain experimental until physical acceptance is recorded.
