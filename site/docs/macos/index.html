PlotIt MCP · Mac guide

From your agent
to paper.

A local macOS companion for agent-assisted USB plotting. macOS 14 or later; no separate Node installation.

Install the Mac app

Get the Apple Silicon build for an M-series Mac or the Universal build for either Apple Silicon or Intel from the Mac companion page when the public release is available. Open the DMG and drag PlotIt MCP.app into Applications before configuring agents.

Open the app and find its menu-bar icon. Development packages are ad-hoc signed and are distinct from the signed, notarized public release. Verify a public download against its SHA-256 checksum. Keep normal macOS security protections enabled.

Set up the plotter

  1. Open Set Up. Choose the machine, USB device, paper format and pen heights. Custom dimensions are in millimetres. Save & Continue preserves changes.
  2. Connect the plotter. Test pen up/down using the saved heights. Position the carriage at the intended drawing origin and secure the paper, then capture the current position as origin.
  3. Configure your agent app through the reviewed installation action. Start a new agent session; restart Claude Desktop if needed. Run the server test and copy the first prompt.

You can also ask the agent to open PlotIt's setup card. It uses the same saved settings and hardware operations. Capturing origin never homes the machine, and the agent must not infer physical placement from an image. Setup controls are unavailable during an active plot.

Allow agent control when ready defaults to On. An explicit Off choice persists. A fresh native companion session, saved configuration, connected plotter and established origin are required before an agent can start a drawing.

Prepare, preview, plot

Ask: “Use PlotIt to check my setup, prepare a small hello-world drawing, show its preview and simulate it before starting.” Inspect the preview, then request the physical plot. Ask for the live progress card to follow it in one place.

The card shows estimated progress and timing, current state and Pause/Resume/Stop. Stop is a controlled stop: wait for motion to settle. Load the requested pen and use Continue in the native companion at physical pen changes. Progress only reaches 100% after the plotter confirms completion.

The web editor and companion remain separate. Export outlined SVG from the editor when you want to exchange artwork. MCP lettering uses bundled centerline stroke fonts.

If something is interrupted

  • No device: check USB and power, refresh devices, and select the exact port if multiple EBB boards are present.
  • Agent configured but disconnected: start a new agent session or restart the agent app, then run the server test.
  • Card not rendered: use the same setup and job tools through text. Interactive UI support depends on the specific client.
  • Settings changed elsewhere: reload saved settings before making new edits. Your draft is not silently overwritten.
  • USB loss or restart: inspect the drawing and restore the physical origin before preparing a new job. Uncertain work is never replayed automatically.

Closing an agent does not cancel a drawing. Use the companion's Pause/Stop controls. Quitting offers Wait and Quit or Stop and Quit while a drawing is active.

Update or remove

Quit while idle, replace the app in Applications and reopen. Keep a backup of the local data folder and previous release. About & Help can open the data folder. Data is stored under ~/Library/Application Support/PlotIt MCP.

To uninstall, remove the PlotIt connection from each configured agent in the app, turn off Open at Login, quit while idle and move the app to Trash. Local drawings, jobs and backups remain until you remove them. The web app is unaffected.

Privacy and support

PlotIt MCP has no account, analytics backend or internet listener. The chosen agent receives requested tool results and previews under its own privacy policy. Review logs before sharing them.

For help, include app version/build, macOS and CPU architecture, agent/client version, plotter model and the observed state in a GitHub issue. Hardware profiles remain experimental until physical acceptance is recorded.
