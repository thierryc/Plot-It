# OpenPlotFont fixtures

Original fixtures from the local OpenPlotFont project, MIT licensed; see LICENSE.
`layout-demo.opf.json` is its portable, compiled OpenType layout example.
`minimal`, `mixed`, and `script` retain the original 0.2 geometry with the version
updated to 0.3, whose geometry-only contract is unchanged. OpenPlotFont's semantic
validator verifies these files as 0.3. They are app tests, not production fonts.
